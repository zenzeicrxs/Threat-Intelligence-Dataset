# Data dictionary
Release metadata: year (integer), status (development or released), quarters (four records), label (Q1–Q4), availability (available_at_source or unavailable), start/end (source-reported ISO dates or null), redistribution_approved (boolean).
Aggregate summary: period (source release label), metric (documented count definition), count (nonnegative integer or null), verification (source_reported or validated), source_reference (file path or report reference).
No individual indicators are included in this public development edition.
