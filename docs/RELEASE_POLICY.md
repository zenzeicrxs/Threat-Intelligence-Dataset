# Annual release policy
Publish only after December 31 of the edition year. Missing quarters are explicitly unavailable and never imputed as zero. Owner authorization recorded in PUBLICATION_AUTHORIZATION.md; require artifact-level rights and sensitivity review, validated counts, schema checks, reproducibility and human approval. Approved data: CC BY 4.0, TLP:CLEAR. Project software: Apache-2.0. No automatic publication or live feed. Use year-based editions with semantic revision numbers, preserve prior versions and record corrections.
