# Limitations
Coverage is partial, not a census. Q1 source label covers 30 days and Q2 source label covers a separate investigation window. Q3 and Q4 are unavailable. No missing periods are zero-filled. Honeypot visibility, sensor configuration and collection criteria bias observations. Q1 and Q2 table counts are not a comparable attack incidence measure. Distinct IP strings are not necessarily distinct actors, hosts or canonical IP identities. Severity is a source classification and not a current reputation verdict. 10,804 Q1 tier records lack timestamps; Q2 download metadata is incomplete. Hash syntax checks do not establish maliciousness. Exact duplicate download rows may be repeated observations; no event removal is asserted. No external enrichment, verified actor attribution, operational blocking feed, or row-level release is provided.
