# Aggregate dataset dictionary
Grain: one metric per source collection label. Count is a nonnegative integer. Verification structural_audit means parsed CSV structural inspection, not validation of maliciousness. Q1 severity counts refer to source tier rows; distinct_ip_strings is a string-level count, not canonical address identity. Hash and URL table rows are not independent incidents. Download rows count source records including the single exact duplicate in Q1. Presence means a nonempty field, except timestamps where N/A is missing. No Q3/Q4 observations or zero-filled metrics are emitted. Q2 collection methodology differs from Q1. These are preliminary reviewed aggregates, not a released row-level intelligence feed.
