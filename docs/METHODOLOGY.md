# Methodology
Maintain immutable locally authorized source snapshots with commit reference and file checksums. Record source release label separately from observation time. Validate syntax, UTC timestamps, nonnegative counts and uniqueness at appropriate table grain. Keep repeated observations distinct from duplicate records. Separate observed facts, third-party enrichment and inference. Missing values remain null; do not manufacture confidence or mappings. Cross-period comparisons require comparable collection definitions and coverage. Report aggregate results with denominators and limitations. Review distribution rights before export or publication.
